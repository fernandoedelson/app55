    {{ tem.index('primeiros-passos') + 1 }} Primeiros passos

      {% call passo('1', 'Entrar') %}

      Use o login e a senha que a administração enviou. A primeira senha é provisória: a aplicação pede uma nova antes de mostrar qualquer coisa. Depois, Trocar senha fica no canto superior direito.

      {% endcall %} {% call passo('2', 'O menu do topo') %}

      Início reúne o relatório por seção. Reunião lista as reuniões de cada mês. {% if 'comentar' in tem or 'curadoria' in tem %}Pendências mostra só o que pede ação sua — o número ao lado é quanto falta.{% else %}Pendências aparece quando houver um encaminhamento com você.{% endif %} {% if 'fechamento' in tem %}Fechamento é onde o mês entra.{% endif %} {% if 'admin' in tem %}Administração cuida de usuários, perfis e permissões.{% endif %}

      {% endcall %} {% call passo('3', 'O que você enxerga') %}

      O seu perfil vê estas seções do relatório: {% for s in secoes %}{{ s.titulo }}{% if not loop.last %}, {% endif %}{% else %}nenhuma ainda — fale com a administração{% endfor %}. Se faltar alguma que você precisa, peça à administração: a liberação é por gráfico.

      {% endcall %} {% call passo('4', 'Claro ou escuro') %}

      O botão Tema alterna. A escolha fica guardada neste navegador.

      {% endcall %}
    {# ------------------------------------------------------------------ relatório #}

    {{ tem.index('relatorio') + 1 }} Ler o relatório

    No Início, cada cartão é uma seção e diz a pergunta que ela responde. Clique para abrir.

      {% call passo('1', 'A barra do relatório') %}

      No alto de cada seção: o caminho de volta, a troca de seção, anterior e próxima, o mês que você está vendo e os atalhos para a Reunião {% if 'comentar' in tem or 'curadoria' in tem %}e para as Pendências{% endif %}.

      {% endcall %} {% call passo('2', 'Período') %}

      As seções que dependem de período têm uma barra de filtro logo abaixo do título. {% if pode_g('recurso:filtro_livre') %}Você pode escolher qualquer intervalo de meses.{% else %}O seu perfil usa os períodos prontos (ano, mês, últimos meses).{% endif %}

      {% endcall %} {% call passo('3', 'Ampliar um gráfico ou tabela') %}

      O ícone ⤢ no canto abre em tela cheia. Na tabela ampliada, A+ e A− (ou as teclas + e −) mudam o tamanho da letra. Esc fecha.

      {% endcall %} {% call passo('4', 'Apontador laser') %}

      Com o gráfico ampliado, o botão ● Laser ou a tecla L acende um ponto vermelho que segue o mouse — para mostrar um número na tela durante a reunião. L de novo apaga.

      {% endcall %} {% call passo('5', 'Tabelas') %}

      Clique no cabeçalho de uma coluna para ordenar (de novo, inverte). O botão CSV baixa a tabela para abrir no Excel.

      {% endcall %} {% if pode_g('recurso:detalhar') %}{% call passo('6', 'Detalhar') %}

      Em muitos gráficos e tabelas, clicar numa barra ou numa linha abre os itens por trás do número — até o cliente e o pedido.

      {% endcall %}{% endif %} {% if pode_g('recurso:destaques') %}{% call passo('7', 'Destaques') %}

      Abaixo dos gráficos, os destaques resumem o que chama atenção no número (o que subiu, o que caiu, o que foge do padrão). Ver gráfico leva ao gráfico que sustenta cada um.

      {% endcall %}{% endif %} {% call passo('•', 'Comentários aprovados') %}

      Quando uma área explica um número e a Controladoria aprova, o texto aparece logo abaixo do título do gráfico, com o nome da área, para todos que veem aquele gráfico.

      {% endcall %}
    {# ------------------------------------------------------------------ reunião #}

    {{ tem.index('reuniao') + 1 }} A reunião do mês

    Todo mês há uma reunião. A aba Reunião lista todas, da mais recente para a mais antiga; cada cartão mostra os atos daquele mês e os encaminhamentos combinados. Abrir a reunião abre em outra aba.

      {% call passo('1', 'Atos e anexos') %}

      A reunião é contada em atos, cada um respondendo uma pergunta (de onde viemos, o que já está vendido, o mês, o resultado…). O que não entra nos atos fica nos anexos, no fim — sem repetir nada do que os atos já mostraram. O menu lateral leva a cada ato e a cada anexo; ☰ recolhe e abre o menu.

      {% endcall %} {% if pode_g('recurso:apresentar') %}{% call passo('2', 'Modo Apresentar') %}

      Apresentar, no rodapé do menu lateral, põe a reunião em tela cheia, um quadro por vez. →, ↓, Page Down ou espaço avançam; ←, ↑ e Page Up voltam; L liga o laser; Esc sai.

      {% endcall %}{% endif %} {% call passo('3', 'O que você vê') %}

      {% if secoes|length == 0 %}Sem seções liberadas, a reunião aparece com os atos marcados como conteúdo restrito.{% else %}Você vê os gráficos que o seu perfil enxerga; um ato sem nenhum deles aparece como conteúdo restrito, para a reunião ter a mesma forma para todos.{% endif %}

      {% endcall %} {% if pode_g('recurso:exportar') %}{% call passo('4', 'Levar o arquivo') %}

      Na lista de reuniões, Baixar o HTML gera o arquivo da reunião para abrir sem a aplicação (sem o painel de encaminhamentos).

      {% endcall %}{% endif %}
    {# ------------------------------------------------------------------ comentar #} {% if 'comentar' in tem %}

    {{ tem.index('comentar') + 1 }} Comentar um gráfico pela sua área

    O comentário mora em cima do dado: é no próprio gráfico que a área explica o número. Enquanto o mês está aberto às áreas (há um prazo), cada gráfico e cada tabela que você vê tem o botão para comentar.

      {% call passo('1', 'Abrir o painel') %}

      Clique em Comentar, ao lado do título do gráfico (ou no botão pequeno no canto de cada figura ou tabela). O painel abre à direita, com o gráfico à vista.

      {% endcall %} {% call passo('2', 'Escrever e salvar') %}

      Escreva o que explica o número — o porquê, não a repetição dele — e clique em Salvar. Fica como rascunho: só a sua área vê.

      {% endcall %} {% call passo('3', 'O botão diz em que pé está') %}

      Comentar (nada escrito) · Rascunho (salvo, não enviado) · Enviado (a Controladoria está lendo) · Devolvido (voltou com um motivo) · Pediram informação (alguém perguntou algo à sua área sobre esse gráfico).

      {% endcall %} {% call passo('4', 'Editar') %}

      Até a Controladoria aprovar, dá para mudar o texto — inclusive depois de enviado (Salvar alteração). A troca fica no histórico. Depois de aprovado, só se ela devolver.

      {% endcall %} {% call passo('5', 'Devolvido') %}

      Veio com o motivo escrito pela Controladoria. Ajuste e envie de novo. Os devolvidos aparecem em Pendências.

      {% endcall %} {% if not pode_g('recurso:consolidar') %}{% call passo('6', 'Quem envia') %}

      O seu perfil escreve; quem envia à Controladoria é o responsável da área (quem tem a permissão Enviar o comentário da área).

      {% endcall %}{% endif %}

    O comentário aprovado aparece abaixo do título do gráfico para todos; os que a Controladoria escolher também entram na reunião.

    {% endif %} {% if 'enviar' in tem %}

    {{ tem.index('enviar') + 1 }} Enviar o comentário à Controladoria

      {% call passo('1', 'Revisar') %}

      Em Pendências → Rascunhos para enviar, cada item leva ao gráfico. Leia o texto da área no painel e ajuste se precisar.

      {% endcall %} {% call passo('2', 'Enviar') %}

      Enviar à Controladoria e confirme. Até ela aprovar, o texto ainda pode ser editado.

      {% endcall %}
    {% endif %} {% if 'solicitar' in tem %}

    {{ tem.index('solicitar') + 1 }} Pedir e responder informação

      {% call passo('1', 'Pedir') %}

      No painel de qualquer gráfico, em Solicitar informação, escolha Para quem (a Controladoria ou outra área que também vê aquele gráfico), escreva o que você quer saber e clique em Solicitar. Também dá para pedir em Pendências → Solicitar informação, escolhendo o gráfico na lista.

      {% endcall %} {% call passo('2', 'Acompanhar') %}

      Em Pendências → Solicitar informação, cada pedido mostra a situação: aguardando a área, em resposta ou respondida. Cancelar retira o pedido.

      {% endcall %} {% call passo('3', 'Responder') %}

      Quando perguntam à sua área, o botão do gráfico fica em destaque (Pediram informação) e o pedido aparece em Pendências → Pediram informação à sua área, com quem perguntou e o quê. A resposta é o próprio comentário no gráfico.

      {% endcall %}
    {% endif %} {# ------------------------------------------------------------------ encaminhamentos (responsável) #}

    {{ tem.index('encaminhamentos') + 1 }} Seus encaminhamentos

    Na reunião, o que fica combinado vira um encaminhamento com um responsável, um prazo e o gráfico a que se refere. Quando o responsável é você:

      {% call passo('1', 'Onde aparece') %}

      Em Pendências → Seus encaminhamentos, e no número ao lado de Pendências.

      {% endcall %} {% call passo('2', 'Concluir') %}

      Escreva o que foi feito e clique em Feito. Só você, o responsável, pode marcar. A Controladoria confirma — ou reabre, se faltar algo.

      {% endcall %} {% call passo('3', 'Prazo') %}

      Passado o prazo sem o Feito, chega um e-mail por dia até a conclusão. O que não for confirmado volta como retomada na reunião do mês seguinte.

      {% endcall %}
    {# ------------------------------------------------------------------ curadoria #} {% if 'curadoria' in tem %}

    {{ tem.index('curadoria') + 1 }} Curar os comentários das áreas

      {% call passo('1', 'O que chegou') %}

      Pendências → Para curar lista o que as áreas enviaram; cada item leva ao gráfico, com o painel aberto. No gráfico, o botão mostra N para curar.

      {% endcall %} {% call passo('2', 'Decidir') %}

      Na seção Curadoria do painel: Aprovar (se mudar o texto antes, vira “aprovado com ajuste”, e a área é avisada), Recusar ou Devolver para reescrever — os dois pedem o motivo, que a área lê.

      {% endcall %} {% call passo('3', 'Levar à reunião') %}

      Ao aprovar, marque Entra na apresentação do mês para o comentário aparecer na reunião, sob o título do gráfico. Dá para ligar e desligar depois pela página de pilotar.

      {% endcall %} {% call passo('4', 'Quem já enviou') %}

      O fim de Pendências mostra, por área, o que está em rascunho, enviado, aprovado e recusado — e o que foi pedido e ainda não respondido.

      {% endcall %} {% call passo('5', 'Histórico') %}

      Cada comentário guarda quem escreveu, enviou, editou e decidiu, e quando. Ações feitas no “ver como” aparecem com o perfil simulado.

      {% endcall %}

    {{ tem.index('conduzir') + 1 }} Registrar encaminhamentos na reunião

      {% call passo('1', 'Sem sair da apresentação') %}

      Com a reunião aberta, o botão Encaminhamentos, no canto inferior direito, abre o painel lateral.

      {% endcall %} {% call passo('2', 'Registrar') %}

      Em Registre a pendência da reunião aqui, escreva o combinado. Escolha o Responsável (a pessoa, com nome e login), o Prazo e Onde: o gráfico que está na tela já vem marcado; dá para trocar por outro gráfico do ato ou pelo ato inteiro.

      {% endcall %} {% call passo('3', 'Acompanhar') %}

      No mesmo painel: Confirmar o que o responsável marcou como feito, Reabrir ou Cancelar. A lista também está em Reunião → Encaminhamentos de cada mês, com a retomada dos meses anteriores.

      {% endcall %}
    {% endif %} {# ------------------------------------------------------------------ pilotar #} {% if 'pilotar' in tem %}

    {{ tem.index('pilotar') + 1 }} Montar a reunião (pilotar)

    Em Reunião → Pilotar (ou Administração → Apresentação do mês), cada mês tem o seu roteiro. Você mexe num rascunho; a reunião só muda quando você gera.

      {% call passo('1', 'Os atos') %}

      Em cada ato: título, a pergunta que ele responde, o tempo, Abrir com cortina (a cortina escura com o logo, como no Sumário) e Entra na reunião. O Ato 6 nasce desligado — é o que você monta mês a mês com o que for importante. + Novo ato cria outro; ↑ ↓ mudam a ordem.

      {% endcall %} {% call passo('2', 'O que entra em cada ato') %}

      + Adicionar ao ato… lista todos os gráficos por seção (os que já estão em outro ato aparecem como “mover”), além de subtítulos, dos filtros de uma seção e da abertura de uma seção. Em cada item: ↑ ↓ para a ordem, Mover… para outro ato, ✕ para tirar (o gráfico volta ao anexo).

      {% endcall %} {% call passo('3', 'Comentários de cada gráfico') %}

      Comentários ▾ mostra o que está aprovado, para curar e pedido. Ali você marca o que aparece na reunião, pede comentário a uma área e abre o gráfico para comentar ou aprovar.

      {% endcall %} {% call passo('4', 'Salvar e gerar') %}

      Salvar rascunho guarda sem mudar a reunião. Gerar apresentação faz a reunião seguir o roteiro. Descartar rascunho volta ao que está gerado; Voltar ao padrão traz o roteiro original (vale quando gerar). Dá para alterar e gerar de novo a qualquer momento.

      {% endcall %} {% call passo('5', 'Anexos') %}

      São automáticos: o fim da página mostra o que vai sobrar em cada anexo. Nada que está num ato se repete — nem gráfico, nem cartão de indicador.

      {% endcall %}
    {% endif %} {# ------------------------------------------------------------------ fechamento #} {% if 'fechamento' in tem %}

    {{ tem.index('fechamento') + 1 }} Fechar o mês

    Em Fechamento, cada mês passa por cinco etapas, mostradas no alto da página do mês: Bases → Processar → Publicar → Abrir às áreas → Fechar.

      {% call passo('1', 'Criar o mês') %}

      Na página Fechamento, escolha o Mês da nova competência e clique em Criar competência.

      {% endcall %} {% call passo('2', 'Subir as bases, aos poucos') %}

      Cada base pede a planilha e a posição dos números (o dia a que eles se referem). O arquivo fica guardado no mês: dá para subir uma hoje e as outras depois. Mandar de novo uma base substitui o arquivo anterior. A base comercial e o Painel de Resultado são obrigatórios.

      {% endcall %} {% call passo('3', 'O que não muda todo mês') %}

      Metas, aportes, apelidos, designers, custos e Fábrica × Loja vêm com Usar a do mês anterior marcado: o mês lê a planilha do mês anterior e o envio fica desligado. Desmarque só quando houver uma planilha nova.

      {% endcall %} {% call passo('4', 'As duas carteiras') %}

      Carteira — posição de fechamento: a VENDAS LOJA do último dia do mês (é a seção Carteira). Carteira dinâmica — posição mais recente: atualize quantas vezes quiser, mesmo com o mês publicado ou fechado; o arquivo novo substitui o anterior e a carteira dinâmica muda na hora, no relatório e na reunião.

      {% endcall %} {% call passo('5', 'Processar') %}

      Libera quando as obrigatórias estão lá. Lê as planilhas com a mesma leitura do relatório aprovado. Se um mês já publicado mudar, a aplicação avisa.

      {% endcall %} {% call passo('6', 'Conferir e publicar') %}

      Ver o que mudou compara com o mês anterior, gráfico a gráfico. A publicação é por gráfico: marque e Publicar os blocos marcados. Se o passado mudou, a justificativa é obrigatória.

      {% endcall %} {% call passo('7', 'Abrir às áreas') %}

      Defina o prazo e clique em Abrir às áreas: as áreas passam a comentar. Salvar o prazo muda o prazo depois.

      {% endcall %} {% call passo('8', 'Fechar') %}

      Fechar o mês encerra os comentários (os aprovados continuam no relatório). Se precisar, Reabrir às áreas. Um rascunho que não serve pode ser descartado.

      {% endcall %}
    {% endif %} {# ------------------------------------------------------------------ administração #} {% if 'admin' in tem %}

    {{ tem.index('admin') + 1 }} Administração

      {% call passo('1', 'Usuários') %}

      Novo usuário: login, nome, e-mail e perfis. A senha provisória aparece uma vez, para você repassar; a pessoa troca no primeiro acesso. Resetar senha gera outra e tira a pessoa de todos os aparelhos. Usuário bloqueado por tentativas erradas se desbloqueia ali. Desmarcar Ativo tira o acesso sem apagar o histórico.

      {% endcall %} {% call passo('2', 'Perfis e permissões') %}

      Cada perfil libera gráficos (seção a seção, gráfico a gráfico) e recursos, agrupados em Leitura do relatório, Reunião do mês (Modo Apresentar, Pilotar a apresentação), Comentário da área (Comentar, Enviar, Curar) e Fechamento do mês. Uma pessoa com mais de um perfil soma o que cada um libera. Este guia se ajusta sozinho às permissões.

      {% endcall %} {% call passo('3', 'Ver como um perfil') %}

      Mostra a aplicação exatamente como o perfil vê. É o jeito de testar uma área de ponta a ponta: no “ver como”, os comentários gravam como a área (e ficam no histórico como feitos por você); o resto é só leitura. Sair do modo, na faixa amarela, volta.

      {% endcall %} {% call passo('4', 'Auditoria') %}

      Tudo o que muda algo fica registrado: quem, quando, de onde e se foi no “ver como”.

      {% endcall %} {% call passo('5', 'Backup') %}

      Baixa o banco e os dados das competências num .zip (tudo ou um mês). Guarde fora do GitHub.

      {% endcall %}
    {% endif %}
